# Abigail Realtor Website

Next.js 15 + TypeScript rebuild of [abigailrealtor.com](https://abigailrealtor.com) for Abigail Anderson (John L. Scott, King County WA).

```bash
npm install
npm run dev    # http://localhost:3000
npm run lint   # eslint && tsc --noEmit
```
